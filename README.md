# Unsent: The Micro-Confession Sprint

A two-part micro-confession for [Unsent: The Micro-Confession Sprint](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba): a `To:` line naming who the unsent message was meant for, and the message itself, one line written exactly as it was typed — no explanation after it.

Run `python3 main.py` and it writes the confession to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). Python standard library only.
